# Agri Predictive Analytics Model

> **All data in this project is SYNTHETIC (generated by src/data_gen.py). Results demonstrate the methodology, not real agronomic findings.**

Forecast district-crop yield (quintal/ha) on **31 August** for six Vidarbha districts and seven crops, explain the drivers, and turn the forecast into procurement priorities. Fictional Nagpur agritech scenario (internship project by Dev Mukesh Lohar).

| (b) Test MAE within 5% of validation MAE | **PASS** | val 1.474 vs test 1.505 q/ha (gap +2.1%) |
| (c) Top-5 SHAP drivers make agronomic sense | **PASS** | cum_rainfall_june_aug (ok); rainfall_vs_normal_ratio (ok); season (ok); soil_organic_carbon_pct (ok); soil_ph (ok) |

Top-5 SHAP drivers: Cumulative rain Jun-Aug, Rain vs normal, Season (Kharif/Rabi), Soil organic carbon, Soil pH. Caveats (see model card): the validation gain versus last-year's yield is inflated by 2019 (post-drought); criterion (c) is a judgment; the worst test error is a cleaning bug, not a model error.

```bash
pip install -r requirements.txt
python src/data_gen.py                      # synthetic raw data -> data/raw/
python src/cleaning.py                      # -> data/interim/agri_yield_cleaned.csv (+ cleaning_audit_report.json)

python src/evaluate.py                      # first use of the test period, PASS/FAIL, SHAP, PDP
python src/procurement_and_fairness.py
python src/case_study.py
python src/build_eda_notebook.py && python src/build_notebook.py
jupyter nbconvert --to notebook --execute --inplace notebooks/agri_yield_analysis.ipynb
python src/build_deliverables.py            # model card, deck, Word report, README
python src/predict.py
```
Random seed 42 everywhere. The test period (2022-2024) is never loaded by `models.py`.

## Method in one paragraph
Cutoff 31 August; only data known by then. Train 2008-18, validation 2019-21, test 2022-24, expanding-window CV. The model predicts the ratio of yield to a drought-robust "normal" (75th percentile of the last 5 seasons) and multiplies back, which carries the technology trend that trees cannot extrapolate. Feature set and model were chosen by CV, then tuned with Optuna on time-aware CV only.
